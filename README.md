# Data Analytics and Visualization Lab

## Overview
This repository contains the laboratory experiments completed for the **Data Analytics and Visualization** course using **Python** and **Jupyter Notebook**. The experiments cover data handling, statistical analysis, data visualization, hypothesis testing, and predictive modeling techniques.

## Tools and Technologies
- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Seaborn
- SciPy
- Statsmodels
- Plotly
- Bokeh
- Scikit-learn

## Experiments

### Experiment 1
- Installation and Exploration of Python Libraries

### Experiment 2
- Exp2A – Working with Numpy arrays
- Exp2B – Working with Pandas DataFrames
- Exp2C – Reading Data from Text, Excel and Web Sources
- Exp2D – Descriptive analysis of Iris Dataset

### Experiment 3
- Exp3A – Univariate Analysis
- Exp3B – Linear and Logistic Regression
- Exp3C – Multiple Regression Analysis
- Exp3D – Comparative Dataset Analysis

### Experiment 4
- Exp4A – Data Visualization using Normal Curves
- Exp4B – Z-Test
- Exp4C – T-Test
- Exp4D – ANOVA

### Experiment 5
- Exp5A – Building and Validating Linear models
- Exp5B – Building and Validating Logistic Models
- Exp5C – Time Series Analysis

## Learning Outcomes
- Perform data preprocessing and analysis using Python.
- Apply statistical techniques to real-world datasets.
- Create meaningful visualizations for data interpretation.
- Conduct hypothesis testing and regression analysis.
- Build and validate predictive machine learning models.
